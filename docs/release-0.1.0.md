# 0.1.0：有界独立伙伴首版

## 版本定义

应用/两个workspace版本统一 **0.1.0**。这不是协议或数据库版本：协议v1、六核心domain schema2、交流主体DSW2 SQLite schema2、学习主体SQLite schema3、legacy主体schema1分别管理。

版本目标：**单一可信所有者、本机运行、持续保存身份/经历的交流与有界自主学习闭环**。用户明确自主学习是首版必需项；此前只交流的完成结论撤回。自主学习已接通并完成合成离线验收，见[自主学习契约](autonomous-learning.md)。不以六个模块名字宣称长期成熟，也不把权重训练/任意工具或娱乐休息执行自动包含进来。

此文描述源码交付与验收，不自动授权正式主体初始化、安装、部署、Git commit/tag/push或包发布。

## 一键离线验收

```bash
npm run verify:acceptance
```

命令先运行交流脚本（`verify:dialogue`），再运行学习专项（`verify:learning`）。只在临时目录创建合成主体与token，用临时127.0.0.1假上游，经同一实际HTTP/模型适配器链路和学习runner验证：

1. 初始化、唤醒与首轮认识/情感/记忆提交。
2. 停止并重开服务、完整状态恢复、下一轮上下文与交流。
3. 休眠不派发、错误凭据被拒绝、次数耗尽不追加调用。
4. finally关闭监听与存储、清除临时数据；异常非零退出，不输出token或完整私有状态。
5. 学习专项：一次授权两目标自主连续推进、study/assessment答案隔离、本地评分、同主体记忆/聊天召回、共享预算、冷重启接续与停止/取消/故障收费。

该命令不读取真实模型配置/凭据，不访问公网、不启动正式主体，不替代真实模型质量或长期效果评测。

## 已知限制（不得省略）

- 有界自主学习以显式资料授权、前台runner和独立评分为边界，不授权任意搜索、外部工具、生成代码执行；模型不能自评即成长。
- 记忆为完整JSON快照+规则召回，无embedding/FTS/独立正文表；2MiB、常规集合1000项上限，满时明确失败，无自动遗忘/压缩。新study预检完整5条cycle，接续测验2条；不是长期存储扩容。
- 学习是授权本地pack内的自主推进，不是权重训练或开放世界知识搜索；pack文本当前保守拒URL/文件引用，不适合带路径的教材。exact评分只证明本次规则任务；completed不是全通过，查看allGoalsPassed。学习账暂不保存逐call模型标识/token用量。
- 单主体、单可信owner；token不是多人权限系统。数据未加密，无内置删除；失败输入保留台账。
- 不自动迁移旧库、续期/退还额度或重新派发pending；没有成功结果重放/恰好一次交付。
- 无跨进程独占租约；CAS防旧结果覆盖，不保证所有交流只有一个进程发请求。v3学习pending与聊天互斥，但episode边界仍可能竞争；sleep排在FIFO内，不即时抢占在途生成。学习stop持久撤权、拒迟到提交，不保证立刻取消另一进程上游请求。
- 同步SQLite和核心校验不能即时取消；v3每次完整回放，不复用v2前缀缓存，随数据增长变慢，短样本不证明长期容量。
- 模型可能不遵守JSON、生成错误内容或不给候选；整轮拒绝会消耗预占次数。没有静默自由文本降级或自动换模型。
- 直接Node运行已验证；当前环境未安装声明开发依赖/锁文件，标准npm run check不是干净安装已验证，离线类型检查借用宿主工具。
- Pi真实TUI/RPC加载与正式长期部署未验证；未初始化正式主体，未发布npm或Git tag。
