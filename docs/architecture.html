一个持续主体，两条有界运行路径。

曙光的 self、cognition、affect、memory、agency、growth 是同一个主体的职责划分，不是六个 Agent。普通交流经受鉴权的本机 HTTP；自主学习由前台 CLI 直达 runner。两条路径共享主体状态、SQLite 事务所有者和总调用预算，但不共享对外协议路径。模型是边界外的不可信资源，不拥有主体、数据库或授权。

02

同一主体的六核心：职责与真实 cycle 顺序

六个模块属于同一个 SubjectState，均不代表独立 Agent 或服务。

一个 SubjectState · schema 2 · 一个主体

self · 持续身份

身份、性格、values、concerns、兴趣与关系边界。初始化关切不是后天学成；模型投影排除私密认识 / 关系等字段。

self/logic.ts · types.ts

cognition · 认识

带来源与状态的 tentative belief、被替代 / 撤回的历史及临时 workspace。不把自信当事实，也不存思维链。

cognition/logic.ts

affect · 工程情感

从关切与证据评价更新有界情感轴，并按显式时间衰减；启发式状态不是主观感受或意识证据。

affect/logic.ts

memory · 来源经历

经历形成 episode；同主体、scope 内确定性相关召回。内容有来源标签，不意味着已被证实。

memory/logic.ts

agency · 受限选择

从可信活动候选中选择 proposed 意图。提议不是权限；无工具执行、网络搜索或活动副作用。

agency/logic.ts

growth · 候选变化

有证据的小步性格 / 兴趣候选；只有独立可信评估才可能应用。真实交流模型路径不提供可信 eval。

growth/logic.ts

一次 runSubjectCycle 的实际顺序

  1. 校验边界：完整状态 / revision / 时间 / scope / 去重 / awake / authority.stopRequested。stop 是 cycle 调用者策略，不读取 learning_grant。
  2. 追加当前经历：先在分离副本中追加有来源经历并生成 episode memory。
  3. 应用获准候选：只处理 typed belief、memory correction、growth candidate；没有任意 patch。
  4. 可信评估（如有）：只可评估先前 cycle 已存在的候选；本轮新增长不能自提自批。
  5. 评价 affect 与选择意图：校验活动证据，召回记忆、建立 workspace，再生成 proposed 意图。
  6. 整体验证并产出：成功才返回新 revision / event / workspace；任意失败不修改输入状态。

这是纯函数候选循环的全有或全无，不等同于数据库原子事务。持久化 CAS 与事务由 SQLite store 负责。affect 的 6 小时 half-life 是工程衰减启发式；只有新的 cycle 时间戳到来才计算更新，没有计时 daemon。学习 cycle 的 appraisal 为 null、candidate allowlist 为空、可信 growth evaluations 固定为空；本地评分不直接产生新情绪或成长应用。core cycle 的 awake / authority.stopRequested 校验由调用者提供；learning stop grant 不等同于 core stop policy。

cycle.ts · affect/logic.ts · 六核心详细契约

03

交流事务：T1 先扣次，T2 再原子提交

模型 I/O 在事务外。失败不退款、不自动重试；迟到结果须通过最新 attempt 与 revision 检查。

T1 · 不可退款预占

在模型调用之前确认 awake 与 expectedRevision、requestId 未用；先提交调用台账。模型 I/O 不包在 SQLite 写事务中。

T2 · revision fence

锁内重查最新 pending、sequence、awake 与 revision，再运行两个 typed cycles。快照、两条事件、成功问答与 usage 同事务提交。

04

自主学习：一次授权，受限前台连续闭环

自主的是被授权范围内的目标选择与推进，不是自行扩权或后台常驻。0.1.0 必须包含此能力。

资料从本地 pack 读取不等于本地推理：显式配置远端模型 endpoint 时，study 会发送教材与练习题干（不含测验题或私有答案键）；assessment 只会发送测验题干与已保存笔记，不含教材与私有答案键。后续普通交流也可能召回学习笔记并作为有限上下文再次发送。

私有答案键不进入模型投影、主体经历或记忆；它与主体状态位于同一未加密 SQLite 文件的私有 pack 表中，并非物理 secret vault。学习笔记会在后续普通交流中按相关性再次披露。资料包在授权导入时固化，不会每轮从原路径读取。

05

SQLite：v2 交流主体与 v3 学习主体

同一 DSW2 主体库；v3 显式新建并扩展表集，不是对 v2 的原地迁移。

共享主体表 · v2 与 v3 都有

表职责
subject当前 revision + 完整六核心 snapshot JSON。memory records / 经历属于 snapshot，不是独立表。
bootstrap不可变初始 snapshot；作为 typed events 回放起点，与最终 snapshot 比较。
eventsrevision 对应事件 JSON；交流每轮两条 cycle event。学习完成事件可以跨多个 revision，事件行使用最终 revision。
attempts交流 requestId 去重、预占序号、用户输入、状态、回复和 usage；失败记录留在台账。
meta主体固定总调用次数上限；v3 学习与交流共享该上限。

存储格式：DSW2 / SQLite user_version 2；v3 保留全部这些核心表。

学习扩展表 · 仅 v3 新增

表职责
learning_pack授权时复制并校验的不可变 pack JSON，含私有答案键；不逐次从原路径读取。
learning_grant一次性学习子预算及 active / stopped 授权状态。completed / exhausted 由 attempts 与预算派生；stop 不提供重新授权路径。
learning_attemptsstudy / assessment 阶段尝试与提交结果（笔记 / 答案）；与主体事件、revision、预算联动。标准答案键仍只在 pack。

显式 learning-init 新建 DSW2 / user_version 3；没有自动 ALTER 或 v2 原地升级。

存储归属与回放边界

  • 单一所有者：普通交流与学习共用主体快照、SQLite 事务协调及总调用预算；v3 文件仍可由 serve --subject-db 提供交流，不需要 chat sidecar。
  • memory 所在：memory 正文、经历和六核心数据属于 subject snapshot JSON，不存在独立 memory SQL 表。
  • 事件关系：学习完成事件可能跨多个连续 revision；图表/归属表示事务与回放关联，不代表额外 SQL 外键。
  • v2 回放：同一 store 可复用经验证的 replay checkpoint，但逐项比较 bootstrap 与既有 event JSON 前缀；snapshot、attempt 台账及已完成 cycle 来源持续核验。前缀变更或重开则重放。
  • v3 回放：每次读库从 bootstrap 完整重演事件，包含每条学习事件覆盖的多个连续 core cycle，并核验学习台账与最终状态；不复用 v2 前缀 checkpoint。

06

隐私、预算、资源与时间边界

以下为实现中 enforced 的限制；不代表加密、费用结算或任意输入都能成功。

边界实际限制 / 语义含义
HTTP wire请求与响应 ≤ 64 KiB；用户 message ≤ 16,000 字符。请求体 UTF-8 严格校验；本机服务鉴权、Host 校验、拒绝 Origin。字符数与网络字节数不同。令牌是本机控制权限，不是多人授权系统。
模型调用默认 timeout 8 秒，显式配置最大 30 秒；单次生成最多 1024 output tokens。超时、坏 JSON、无效候选皆失败；不降级、不重试、不切换模型。
服务 / 客户端say 服务端累计 deadline 35 秒、客户端 40 秒；控制请求和上传为 10 秒。deadline 含排队时间；取消不等于能即时中止同步 SQLite 操作。
学习 run每次前台 runner 硬期限 10 分钟；每 study / assessment 各调用一次。超时结束当前 run；无后台队列、重试策略或跨进程运行租约。
交流上下文成功历史最多 8 对 / 24,000 字符；只取完整成功问答后缀。总模型消息内容严格 < 40,000 字符。不发送 Pi 会话历史，不发送完整主体状态；超限删旧 pair / 可选投影。
记忆与认识投影相关记忆最多 6 条 / 8,000 字符；相关 belief 最多 8 条。规则字符串匹配，不是向量检索；相关 / 有来源不等于真实。
永久预算主体总 calls 1–10,000；学习子预算 2–32 且 ≤ 总预算；单模型实例 maxCalls 1–10。学习两目标通常四次生成。失败、取消、pending 均不退款；无自动重试。非货币 / token 结算账单。
SQLite 容量snapshot ≤ 2 MiB；经历、memory、processed cycle 等常规集合最多 1,000 项。满容量明确失败；无自动遗忘、摘要、压缩或增长上限规避。
学习输入 / 预检Pack ≤ 64,000 bytes（不是 64 KiB）、最多 16 goals、每组问题最多 8；study 预检 2 次剩余调用额度及 5 个后续 cycle 容量（本阶段实际提交 3 cycle），assessment 预检 1 次额度及 2 个 cycle；每 goal 两阶段成功共写 5 revisions。2 次额度是 study 开始时最低预算检查，不会一次双重预占；study 与 assessment 之间普通交流可能耗尽共享总预算。5 是跨本目标两个阶段的 episode / cycle 空间预检，并非 study 实际 cycle 数。教材是数据，不提供工具执行。
持久隐私SQLite 文件不加密；答案键只由应用逻辑隔离，仍与主体状态位于同一未加密数据库中的 pack 表，不是物理 secret vault。失败输入在台账；无内置删除 / 抗篡改账本。使用可信私有目录并停写后备份。远端供应方会收到实际提示中的教材、题干、笔记及之后可能召回的学习记忆；真实资料 / API 调用须另行授权。
并发与审计：FIFO 仅限单个 SubjectService 实例；pending / CAS 不是跨进程租约，也不保证全局模型调用单飞。模型实例 maxCalls 是内存计数，重启可重置；数据库永久预算不重置。复制 / 恢复数据库会回退本地台账。交流 attempt 保存 model / usage，当前学习台账不记录逐次 modelId / token 用量。交流投影会包含主题相关 concerns，学习经历 / 笔记也可能在后续相关召回中再次披露。
预算与学习状态：额度按生成请求次数永久预占，不等于模型 token、货币扣款或防回滚计费。学习阶段内部 learningStatus 含完整 pack 与 attempts / results；CLI 的 learning-status 必须使用剔除教材、答案、笔记的 safe report。

没有这些基础设施

09

能力边界与未实现的未来候选

“未实现”不是本架构的隐含组成部分；不能从当前数据流推导为已授权能力。

当前边界

能做 / 不能做

  • 能：同主体本机显式交流、持久来源经历 / 相关记忆、有限资料授权的前台学习闭环。
  • 不能：任意网络搜索、调用工具或执行代码；模型自批成长；后台学习；无限记忆；向量检索。
  • 不保证：真实模型总能遵循严格 JSON；测试分数等于一般能力；数据库加密或成为抗篡改账本。
候选设计，不是承诺

需独立评估的后续议题

  • 跨进程 leases：需要 owner / 到期 / 抢占 / 崩溃语义；当前 instanceId 不是锁。
  • 后台学习：需要新调度、可观测性、授权撤销与关机生命周期。
  • 长期记忆：需要容量、可删除 / 纠正、压缩与隐私披露策略；当前没有自动遗忘或向量库。
  • 工具与执行：需逐类 capability、沙箱和用户授权；当前没有 tool adapter。

未来候选各自有独立授权边界

跨进程运行租约

owner / expiry / recovery；不是当前 instanceId。

后台学习调度

撤权 / shutdown / 可观测；当前只有前台 runner。

长期记忆治理

删除 / 压缩 / 容量 / 隐私；当前无自动遗忘 / vector DB。

受限工具能力

逐类授权 / 沙箱 / 审计；当前无工具执行器。

这些候选之间不表示模块依赖或既有数据流；任何扩展均须单独设计、授权与验证。
